# Agent Behavioral Rules

## Code Modification Scope (Vibe Coding)
When the user asks you to "vibe code" or modify code, strictly isolate your changes to the specific components, files, or logic flows that are directly affected by the requested feature or fix. 
Do not make unrelated changes, refactorings, or formatting updates to surrounding code or other areas of the project. Ensure that all modifications are surgical and leave unrelated areas completely unaffected.
