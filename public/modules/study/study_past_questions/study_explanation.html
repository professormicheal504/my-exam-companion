Further Mathematics WAEC 2017
If logy 1⁄8 = 3, find the value of y.
A -2
B - 1⁄2
C 1⁄2 Correct
D 2
Explanation Correct Option C
logy 1⁄8 = 3  ⟹  y3 = 1⁄8  (Laws of logarithm) y3 = 1⁄8 = (1⁄2)3 Equating both sides, we have y = 1⁄2
